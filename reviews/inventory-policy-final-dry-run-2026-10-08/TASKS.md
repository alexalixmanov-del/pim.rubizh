# Сохранённый план PIM и условия завершения RC

Этот dry-run не отменяет прежние задачи. Production, deployment, sync и публикация запрещены до отдельного подтверждения. Состояния ниже различают принятую интеграцию, review-доработки и недостающие реальные inputs.

| Задача | Текущее состояние / следующее действие |
|---|---|
| Canonical taxonomy и classification | Принята интеграция 143 categories: исходные 134 IDs + 9 утверждённых, manual locks приоритетны, SAFE_AUTO отдельно от LIKELY/AMBIGUOUS. Не пересматривать финализированные категории при inventory работе. |
| Размеры | Сохранить EXACT_SIZE / SIZE_LIST / RANGE / ONE_SIZE / NO_SIZE_REQUIRED / SIZE_CONFIRMATION_REQUIRED. allowed_sizes отдельно от реальных SKU; range не создаёт fake SKU/stock. Предыдущий контрольный импорт: exact=4199, options without SKU=1145. |
| MODEL → COLOR → SIZE/SKU | Сохранить SKU, фото по цветам, цены, остатки и supplier bindings; similar name alone не объединяет модели. Supplier STATUS не доказывает наличие каждого варианта в shared SKU группе. |
| Inventory semantics | M-WIN/Киборг/Армолайн STATUS приняты; UKR-TEC Prom STATUS подтверждён пользователем в этом этапе. Tactical Belt QUANTITY остаётся одним supplier-level исключением до подтверждения смысла чисел. Рабочие policies пока не назначены. |
| Давность и last-valid observation | Сохранить последнее valid observation до новой valid записи/manual correction; freshness metadata only; imported_at не observation. Не обнулять missing/invalid update; только явный supplier expires_at может быть expiry. Review-доработки подготовлены, но финальный контракт требует новых modes. |
| RC: заказ и оплата | Сохранить order_submission_allowed / payment_allowed / requires_order_confirmation, ORDER_ON_REQUEST отдельно, PREORDER/request требуют менеджера. Убрать mandatory numeric quantity для STATUS/подтверждённого FEED_PRESENCE. Адаптировать schema/export/SIMPLE/mock API/tests под nullable quantity и подтверждённое availability evidence. Текущая numeric-only review сборка не финальный RC. |
| Idempotent import и защита данных | После inventory integration заново preview→apply на копии, второй идентичный импорт, rollback/abort. Все LOST_*, duplicates, PRODUCTION_WRITES=0, manual locks unchanged. 8 существующих product locks сохраняются. Предыдущая проверка не заменяет проверку нового контракта. |
| Описания и перевод без платного AI | Сохранить факты поставщика, характеристики и комплектацию, исправления бесплатного генератора/локализации. Отсутствующий desc не автоматически архивирует восстановимый товар; не придумывать характеристики. Не заменять полный исходник коротким резюме. Проверить после новых import mappings. |
| Фото, скрытие и восстановление | 0 usable photos блокирует публикацию; скрытие/архив в будущем reversible. В review import нельзя автоматически публиковать, архивировать или скрывать товар. |
| Комплекты | Сохранить подбор реальных вариантов, количество компонентов, совместимость, размеры, цены и supplier links. Не объявлять UNKNOWN stock/size option реальным остатком и не резервировать fake quantities. Реальная проверка при заказе требует shop backend. |
| Маржа и цены | Сохранить согласованные 30% / 25% / 20% и действующие price/margin guards. Inventory dry-run не меняет закупочные/продажные цены; после integration подтвердить LOST_PRICES=0 и calculated prices unchanged. |
| Исключения и упрощение интерфейса | Группировать по supplier/rule/category/pattern; показывать ясную причину, не тысячи одинаковых вопросов. Не удалять данные или manual locks ради уменьшения счётчика. Сохранить ранее внесённые исправления кнопок/feedback; live UX отдельно проверить. |
| Магазин / selector / gallery / checkout | Нужны реальные файлы страницы товара (цвет/размер/gallery), корзины и server checkout, создания платежа, manager confirmation, обработки /pim/sync и схема orders/variants. Точные repo paths неизвестны; mock не заменяет их. Магазин пока не мигрирован на новый контракт, /pim/sync заблокирован. |
| REAL_SOURCE_COMPATIBILITY / автопрайсы | По одному настоящему XLS/XLSX/CSV/XML или URL для каждого из пяти supplier, actual sheet/header/mapping и explicit availability fields. Backup и audit CSV не исходные прайсы. Read-only checker подготовлен; production gate BLOCKED до реальной проверки. Подтверждение inventory semantics не подменяет workbook compatibility. |
| Итоговая 10.9.3 RC сборка / hosting | Завершить contract integration, весь новый контрольный импорт, тесты, воспроизводимый review archive, SHA и RC report. До отдельного подтверждения не устанавливать на adm.tools/production и не запускать массовую публикацию. |

Две supplier-level confirmations вместо разбора 2491 товаров: UKR-TEC уже закрыт ответом о формате; Tactical Belt осталось уточнить «Наличие = количество единиц по supplier SKU». Когда понадобятся обновлённые прайсы, сохранить исходную задачу подготовить текст запроса поставщикам о постоянных ссылках и описании формата.
