## Размеры

Из 295 исходных вопросов автоматизировано **194**, осталось LIKELY **0**, AMBIGUOUS **101**. Внутри исходной очереди подтверждены **56 точных SKU-size связей**, **9 ONE_SIZE**, **6 случаев NO_SIZE_REQUIRED**. На уровне SKU автоматизированы 243 результата, 183 остаются неоднозначными. Числа SKU и вопросов различаются, поскольку вопрос может содержать несколько вариантов.

SAFE_AUTO по диапазону/списку означает закрытый вопрос о трактовке **ассортимента модели**, а не подтверждённый размер неизвестного supplier SKU. Его связь и stock остаются SIZE_CONFIRMATION_REQUIRED, обычный checkout запрещён.

По всему активному каталогу развёрнуто **111 диапазонов моделей**, нормализованы списки **126 моделей**, подготовлено **1067 size options с UNKNOWN stock**. NO_SIZE_REQUIRED — **2102 товаров**, ONE_SIZE — **10 SKU**. Указанные options не добавлены как реальные варианты и не получили новые SKU.

**Дополнительный результат полной проверки:** 1 221 существующий SKU ещё не имеет безопасно подтверждённой самостоятельной связи размер → SKU/stock. Сюда входят разрешённые options и старые виртуальные варианты с общим supplier SKU, которые прежняя очередь ошибочно считала определёнными. Подтверждённые ручные размеры/mappings не изменены; мы не удаляли эти SKU. Это не 1 221 ручное решение владельца: подготовлены пять пакетных запросов поставщикам.

## Остальные группы и короткая проверка

134 категории определены по самому изделию и явным данным источника. Аксессуар/компонент не становится категорией целого товара. Сохранён исходный путь категории; цены после нормализации не изменились. Для неизвестных изделий без подходящего leaf (например часы/флаги) новый leaf не создавался — это реальное ограничение замороженной taxonomy.

По цветам автоматически обработаны 50 SKU, в том числе буквальные рисунки поставщика. «Карбон» не назначен чёрным цветом, «Різні кольори» не превращено в отдельный подтверждённый оттенок. LIKELY: «Сырий» → вероятное «Сірий», пока без применения. «Камуфляж» разрешался только для конкретного SKU с отдельным подтверждением рисунка.

Объединены 20 семейств (21 лишняя карточка), все 8 734 исходных варианта сохранены. Архивные source cards/старые ID и источники фотографий сохранены. Только похожего названия недостаточно. 18 семейств остаются LIKELY, ещё один LIKELY — технический лимит 53 вариантов; 10 семейств неоднозначны. Куртка «Хуртовина» с 53 вариантами не разделялась и не обрезалась ради лимита 50.

78 LIKELY сведены к **27 пунктам** короткого списка. Основные: состав защиты/комплектов, футболка vs UBACS, семейства без общего кода, опечатка цвета и лимит 53. Подробности: `audit/final-dry-run/likely-grouped.md`; подробные списки, preview и supplier requests доступны в приватном рабочем каталоге и не публикуются в Git.

## Бизнес-правила

1. Нулевой набор допустимых фото или известные broken/placeholder URL блокируют публикацию; фото-исключение обратимо. В копии одна карточка без фото уже исключена, новых архивирований по фото 0. Неизвестная доступность внешнего URL — PHOTO_VERIFICATION_REQUIRED, не причина архивировать тысячи карточек наугад. Живые изображения по всем URL не скачивались: 49 468 ссылок/привязок ещё требуют worker verification.
2. Отсутствие описания не архивирует. 19 карточек восстановлены из автоматического архива в контент-исключения. Для них нет достаточных supplier facts, поэтому описание не придумано. Восстановление из фактических supplier attributes реализовано и проверено; в этих 19 карточках данных для него недостаточно.
3. Пустой size не создаёт PREORDER. Размерный товар без SKU-size evidence остаётся SIZE_CONFIRMATION_REQUIRED; модельные options только для запроса подтверждения.
4. Исторические данные дают один явно подтверждённый источником PREORDER; 2 182 out SKU не превращены в под заказ. Если срок не сообщён, остаётся null. Настройка 36 часов сохранена, все 8 734 исходных предложения просрочены на дату dry-run: её обход включён только для согласованной изолированной симуляции.
5. Canonical taxonomy, aliases, supplier mappings, confirmed size mappings, manual locks и их значения сохранены. Показ options на витрине, реальная загрузка фото и checkout требуют серверной интеграции — [точный список](BLOCKED-TASKS.md). До неё отчёт не подтверждает готовность полного покупательского пути.

```text
LOST_SKU = 0
LOST_VARIANTS = 0
LOST_PHOTOS = 0
LOST_PRICES = 0
LOST_STOCK = 0
LOST_CATEGORIES = 0
```

Сравнены каждый исходный вариант и весь supplier offer, фотографии с привязками product/SKU/supplier, ручные поля, исходные/исторические категории, config и taxonomy. Отдельно сверены рассчитанные цены для каждого SKU. Проверка прерывается при изменении исходного offer/variant или потере любого ресурса, а не только при отличии общего количества.

**535 проверок пройдены:** 486 существующих, 49 новых. Browser preview: фильтры статуса/группы, поиск SKU, раскрытие доказательств, ошибок JavaScript нет. Полный путь заказа и внешние URL фото не подтверждены этими тестами.
