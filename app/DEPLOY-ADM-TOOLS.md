# Установка PIM 10.9.0 через терминал adm.tools

Папка сайта: `/home/xk589064/rubizh.shop/pim/`, пользователь `xk589064`. Используйте встроенный терминал `>_` на хостинге. Скачивать архив на компьютер не требуется.

Сначала сохраните свежую резервную копию из действующей PIM. Затем в терминале выполните:

```bash
curl -fL --connect-timeout 20 --max-time 60 \
'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/deploy/pim-10.5.2-terminal/releases/pim-10.9.0/install-from-github.sh' \
-o /tmp/rubizh-pim-install.sh &&
bash /tmp/rubizh-pim-install.sh
```

Установщик скачает архив на сервер, проверит SHA-256, сохранит старые файлы вне публичной папки и установит только HTML и необходимые ресурсы. При сбое замены запускается откат. После завершения выводятся путь резервной копии и команда ручного отката. Посторонние файлы сайта и сервер/API сохраняются. Каталог браузера не заменяется.

Откройте прежний адрес `https://pim.rubizh.shop/` в том же браузере и профиле, обновите страницу через Ctrl+F5 или Cmd+Shift+R. Проверьте версию 10.9.0, наличие каталога и сохранение карточки после перезагрузки. Не очищайте хранилище браузера. Категории переносятся отдельно: «Категоризація» → dry run → проверка спорных позиций → применение миграции. См. [CATEGORIES-10.7.md](CATEGORIES-10.7.md).

Если ZIP уже загружен в папку сайта, альтернативная команда:

```bash
cd /home/xk589064/rubizh.shop/pim/ &&
unzip -p rubizh-pim-10.9.0.zip deploy-adm-tools.sh > /tmp/rubizh-pim-deploy-10.9.0.sh &&
bash /tmp/rubizh-pim-deploy-10.9.0.sh rubizh-pim-10.9.0.zip
```

Установщик явно сообщает об отсутствующем файле или ошибке. Без архива эта альтернативная команда обновление не выполняет. Серверная проверка заказа и автоматическое обновление при закрытом браузере устанавливаются отдельно после получения исходников магазина и ссылок поставщиков.

Новые правила и объединение моделей применяются отдельно через проверку на экране «Публикация». См. [SIMPLE-10.9.md](SIMPLE-10.9.md).
