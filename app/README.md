Бесплатный генератор, собственный словарь перевода и работа с подробными характеристиками: [CONTENT-FREE.md](CONTENT-FREE.md). API и новая серверная часть для генератора не нужны.

```sh
npm ci --ignore-scripts
npm test
npm run serve
```

Откройте http://localhost:8765/rubizh_pim.html. `npm run build` переносит изменения из `lib/*.inc.js` в HTML. Проверки не требуют каталога пользователя и не обращаются к production.

Перед переносом на хостинг сохраните резервную копию и проверьте новую сборку отдельно. Сервер магазина не входит в эту сборку. Исторические результаты в `verification/` и `pim-audit.md` относятся к исходному архиву; актуальные доказательства находятся в `../audit/` репозитория или `audit/` установочного ZIP.
