# Автоматизация на хостинге и проверка заказов

## Уже работает в PIM

Карточка поставщика позволяет сохранить HTTPS-ссылку, интервал и включить проверку при открытой PIM. Первое скачивание проходит обычный предпросмотр. После подтверждения профиля колонок можно разрешить автоматическое применение. Изменение структуры файла, подозрительно неполный файл, сетевая ошибка или сбой сохранения прекращают автоматическое применение. Резкий рост закупки остаётся отдельным решением; отсутствующие в файле предложения автоматически не обнуляются.

У источника должен быть доступ из браузера по CORS. Закрытые источники и обновления при закрытой PIM требуют серверного подключения. Периодическая проверка в браузере не является серверным cron.

## Готовый загрузчик для cron

`fetch-supplier-feeds.py` использует стандартный Python 3, проверяет HTTPS, размер и тип результата, записывает файлы атомарно с правами 0600 и сохраняет предыдущий хороший файл при ошибке. Его `status.json` явно содержит `applied_to_pim: false`: скачивание само по себе не обновляет каталог, наличие или магазин.

Приватный конфиг вне папки сайта:

```json
{"sources":[{"id":"supplier-id","url":"https://supplier.example/prices.xlsx","enabled":true}]}
```

Рекомендуемые пути на этом хостинге:

- конфиг: `/home/xk589064/.pim-feed-config.json`;
- кэш: `/home/xk589064/.pim-price-cache/`;
- скрипт: `/home/xk589064/.pim-tools/fetch-supplier-feeds.py`.

Пример задачи каждый час после заполнения реальных ссылок и проверки доступности Python 3:

```cron
0 * * * * python3 /home/xk589064/.pim-tools/fetch-supplier-feeds.py --config /home/xk589064/.pim-feed-config.json --output /home/xk589064/.pim-price-cache --web-root /home/xk589064/rubizh.shop/pim
```

Для подключения к PIM сервер должен отдать аутентифицированному сотруднику файл по ID источника, без произвольного URL в запросе, и метаданные последней успешной загрузки. Проверка доступа должна соответствовать вашей серверной базе. Файлы закупочных прайсов нельзя класть в публичную папку сайта или отдавать без проверки доступа.

Постоянные ссылки поставщиков, доступ к серверной базе и исходники магазина пока не предоставлены. Cron и его подключение не устанавливаются автоматически вместо неизвестной серверной системы.

## Комплекты при оформлении заказа

Готовый контракт описан в `../server-contract.md`; модуль `../lib/kits.js` можно использовать и на Node.js. Нужна интеграция в обработчик заказа именно вашего магазина:

1. Получить утверждённую версию комплекта и актуальные цены/остатки с сервера.
2. Проверить выбранные SKU, размер, рост, количество каждой позиции и совместимость плит.
3. Посчитать полную цену и дату готовности; изготовление разрешать только по подтверждённой политике поставщика или позиции.
4. В одной транзакции зарезервировать общий складской пул и записать заказ; при нехватке любой позиции откатить весь резерв.
5. Подтвердить клиенту результат и возвращать PIM достоверное подтверждение публикации.

Без исходников и схемы хранения магазина этот обработчик нельзя корректно подключить к оформлению заказа. Само обновление HTML не меняет сервер магазина.
