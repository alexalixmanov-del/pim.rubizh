Канонические категории, supplier mapping, безопасный dry run и ручная проверка. Бесплатно, без AI API.

[Отчёт по всем 15 пунктам](VERIFICATION.md), [справочник 134 ID](canonical-categories.json), [полное old → new mapping](old-category-mapping.json), [результаты импортов](category-supplier-imports.json), [контракт магазина](server-contract.md).

После установки на прежний адрес: обновление страницы → «Категоризація» → dry run → проверка → применение миграции. Сервер магазина требует поддержки canonical_category_id v1; его исходники отсутствуют. На production пока ничего не установлено.
