# РУБІЖ PIM 10.7.0

Канонические категории, supplier mapping, безопасный dry run и ручная проверка. Бесплатно, без AI API.

[Отчёт по всем 15 пунктам](VERIFICATION.md), [справочник 134 ID](canonical-categories.json), [полное old → new mapping](old-category-mapping.json), [результаты импортов](category-supplier-imports.json), [контракт магазина](server-contract.md).

242 теста приложения, 75 проверок отображения и 13 проверок установки/отката прошли. Все 3113 товаров и 8734 варианта сохранены; изменений цен и остатков из-за миграции — 0. Оригинальные прайсы не предоставлены: тестовые файлы восстановлены из backup. 260 неизвестных товаров и 260 конфликтов оставлены для решения владельцем. Пользовательский каталог исключён из публичного архива.

После установки на прежний адрес: обновление страницы → «Категоризація» → dry run → проверка → применение миграции. Сервер магазина требует поддержки canonical_category_id v1; его исходники отсутствуют. На production пока ничего не установлено.

Установка через терминал adm.tools без скачивания на компьютер:

```bash
curl -fL --connect-timeout 20 --max-time 60 'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/7833d8684417d7dfbcb55b31e18b87763d8e5457/releases/pim-10.7.0/install-from-github.sh' -o /tmp/rubizh-pim-install-10.7.0.sh && bash /tmp/rubizh-pim-install-10.7.0.sh
```

Установщик скачивает неизменяемый архив с проверкой SHA-256, сохраняет старые файлы вне публичной папки и печатает команду отката. Путь по умолчанию: `/home/xk589064/rubizh.shop/pim`. API/посторонние файлы сохраняются. Проверено реальное скачивание опубликованного установщика и архива, установка в отдельную папку и откат: [8 проверок](terminal-download-check.json). Это проверка доставки, не установка на production.
