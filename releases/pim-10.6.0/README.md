# PIM 10.6.0

Подготовленная сборка для того же адреса https://pim.rubizh.shop/. Архив включает собранное приложение, модули, исходники новых функций, проверки и инструкции. Каталог товаров, личные настройки и секреты пользователя не включены. Развёртывание на хостинге выполняет владелец через терминал adm.tools.

Изменения:

- Постоянный результат основных действий, блокировка повторных операций, повтор записи при ошибке и завершение проверки базы до начала работы.
- Единый раздел «Проблемы» с фильтрами и действиями; допустимые совпадения размеров/цветов не считаются ошибками.
- Упрощённое основное меню с доступными на телефоне шестью разделами.
- Автопрайсы HTTPS: первое подтверждение колонок/листа, последующее автоматическое применение, проверка структуры/полноты, резервная копия и обработка ошибок.
- Отдельные правила наличия и подтверждённого изготовления для каждого предложения.
- Необязательное применение проверенных бесплатных описаний после импорта, сохранение фактов и защита ручного текста.

155 автоматических проверок JS, 8 проверок Python-загрузчика, 72 сочетания экранов/ширин, сценарии сохранения/перезагрузки/автопрайсов в Chromium. Все 3 113 товаров и 8 734 SKU из копии сохранены при проверке миграции. Установщик отдельно проверяется с успешной установкой, ручным и автоматическим откатом.

Ссылки поставщиков пока не предоставлены. Расписание PIM работает при открытом браузере; подготовленный серверный загрузчик не установлен и не подключён к базе. Серверный обработчик заказа/резервирования комплектов требует исходников магазина и не изменён этой сборкой. Платные AI API не используются.

В терминале adm.tools после свежей резервной копии:

```bash
curl -fL --connect-timeout 20 --max-time 60 \
'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/3b3c839524be4241a840ba597510662c13be58ce/releases/pim-10.6.0/install-from-github.sh' \
-o /tmp/rubizh-pim-install.sh &&
bash /tmp/rubizh-pim-install.sh
```

Скрипт скачивает и проверяет архив на сервере, сохраняет старые файлы вне публичной папки и устанавливает необходимые ресурсы. По завершении обновите прежний адрес в том же браузере/профиле через Ctrl+F5 или Cmd+Shift+R и проверьте версию 10.6.0 и сохранение карточки. На хостинге обновление ещё не подтверждено.

Готовый запрос поставщикам: [SUPPLIER-REQUEST.md](SUPPLIER-REQUEST.md).

Проверка опубликованного установщика: [terminal-download-check.json](terminal-download-check.json). Скачивание, SHA-256, установка в отдельную папку и откат прошли; production не изменялся.
