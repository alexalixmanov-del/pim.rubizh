# Установка PIM 10.9.0 через терминал adm.tools

Скачивание архива на компьютер не нужно. Вставьте в терминал:

```bash
curl -fL --connect-timeout 20 --max-time 60 \
  'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/4ab53e1ed4e6a4cc09b20b98d9821165f672eeb6/releases/pim-10.9.0/install-from-github.sh' \
  -o /tmp/rubizh-pim-install-10.9.sh &&
bash /tmp/rubizh-pim-install-10.9.sh /home/xk589064/rubizh.shop/pim
```

После успешной установки обновите pim.rubizh.shop через Ctrl+F5 / Cmd+Shift+R в прежнем браузере. Не очищайте данные браузера. Проверьте версию 10.9.0. В «Публикация» нажмите «Проверить текущий каталог», просмотрите сводку, затем «Применить с резервной копией». Это включает новые правила и объединение надёжных групп моделей. Полный откат применения доступен в автоматической обработке; откат файлов — команда из установщика.

Архив закреплён за коммитом и SHA-256. Старые файлы сохраняются вне webroot; существующий API и посторонние файлы не заменяются. Команда проверена на отдельной папке, а не на production.

На стороне PIM реализованы модель, цветовые галереи и выбор SKU. Изменение переключателей самой витрины требует кода магазина и поддержки model_colors v1. После активации правил неподдерживаемое API выдаёт понятную ошибку до отправки несовместимых данных. См. SIMPLE-10.9.md и server-contract.md.
