# PIM 10.9.0: проверенная поставка

Готова клиентская PIM с простым меню, автоматическими исключениями, правилами заявок под заказ и отдельными галереями цветов одной модели. Для применения предусмотрены проверка каталога, полная резервная копия, запись с подтверждением и откат. Установка runtime отдельно от применения правил.

| Область | Проверенный результат |
|---|---|
| Автоматические тесты | 450 passed, 0 failed, 0 skipped |
| Браузер | 42 раскладки: 7 экранов, 3 ширины, 2 темы; ошибок JS/переполнения нет |
| Реальные действия | Preview, apply, общий ответ о цвете, перезагрузка, откат; смена галереи/размеров/точного SKU; сохранность несохранённых полей |
| Каталог | Все 3113 исходных записей сохранены; 8734 SKU с неизменными ценами, остатками и предложениями |
| Пример Husky Extreme | 3 исходные карточки → 1 модель, 3 цвета, 17 SKU, 30 фото |
| Сохранность | Исходные названия, тексты, фото, категории, ссылки и ручные блокировки сохранены; SKU перенесены в модель |
| Неполный контент | 20 автоматически архивируемых карточек; это восстановимый архив, не физическое удаление |
| Импорт | 5 поставщиков, повтор файла, новый каталог, цена, остаток, название, фото, категория, новый/исчезнувший вариант; строки восстановлены из копии |
| Масштаб группировки | Синтетические 10000 карточек → 2500 моделей с 10000 SKU; холодная группировка/повтор/миграция измерены отдельно |
| Публикация | Пакет из 150 подтверждений сохраняется перед сбоем следующего пакета; повтор отправляет только оставшуюся карточку |
| Скрытие | Только точный ACK hidden_ids; явное скрытие неполной/объединённой карточки без локальных хэшей |
| Совместимость магазина | Неподдерживаемые product_model/model_colors/order_on_request блокируются до POST с сообщением |

Синтетическая проверка не доказывает точность на 10000 реальных товаров и не измеряет всю публикацию. Полная текущая копия имеет старые отметки наличия: разрешённые к публикации варианты становятся заявками с неизвестным сроком, а не подтверждённым сегодняшним остатком. Работоспособность URL картинок не проверялась сетевыми запросами. Оригинальные прайсы поставщиков не предоставлены.

Названия не доказывают идентичность изделий. Автоматически объединены только три группы с достаточными свидетельствами; сомнительные группы без технических противоречий требуют одного ответа на группу. Итоговые числа вопросов и публикации находятся в model-colors-10.9-catalog-summary.json; каталог ещё не объявлен полностью готовым без вопросов.

Не реализованы в этой поставке: серверная транзакция/ревизии, переключатели витрины и её обработчик галерей, редиректы старых карточек на сервере, подтверждение менеджером и резервирование заказов, автономные обновления без браузера. Исходников магазина нет. API-контракт подготовлен; конечная проверка сайта остаётся после изменения его кода.

Работа на хостинг не отправлялась. Терминальный установщик, проверка контрольной суммы, установка/откат файлов и чистое облачное окружение проверяются отдельно в документах поставки.
