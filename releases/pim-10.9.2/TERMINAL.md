# Установка PIM 10.9.2 через adm.tools

Вставить в терминал хостинга:

```bash
curl -fL --connect-timeout 20 --max-time 60 \
'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/cd5249e398a0d5683f2fb5efbe98b82da4422720/releases/pim-10.9.2/install-from-github.sh' \
-o /tmp/rubizh-pim-install-10.9.2.sh &&
bash /tmp/rubizh-pim-install-10.9.2.sh
```

Архив заранее загружать в папку сайта не нужно. Установщик сам скачает его из закреплённого коммита, проверит SHA-256, сохранит предыдущие файлы за пределами публичного сайта и установит runtime. Серверные файлы магазина сохраняются.

После успешной установки открыть PIM в прежнем браузере и профиле и обновить страницу Ctrl+F5 / Cmd+Shift+R. Не очищать хранилище. Проверить версию 10.9.2. Правила 30 / 25 / 20 применятся при первом запуске после резервной копии; ручные цены и прайсы сохранятся. [Подробности](MARGIN-10.9.2.md).

Для магазина требуется [SHOP-PRICING-TZ.md](SHOP-PRICING-TZ.md). Без поддержки `pricing_policy_version:1` синхронизация остановится с объяснением; нельзя считать этот установщик обновлением витрины и оформления заказа. Продакшен не изменялся при подготовке выпуска.
