# Установка PIM 10.8.0 через adm.tools

Выполните в терминале хостинга:

```bash
curl -fL --connect-timeout 20 --max-time 60 'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/6ec590cba099fe4bfde8e7cee6082b7f1c7606f6/releases/pim-10.8.0/install-from-github.sh' -o /tmp/rubizh-pim-install-10.8.0.sh && bash /tmp/rubizh-pim-install-10.8.0.sh
```

Архив скачивается сервером напрямую из GitHub; скачивать его на компьютер не требуется. Проверяется SHA-256, сохраняются прежние файлы вне webroot и выводится точная команда отката. По умолчанию обновляется `/home/xk589064/rubizh.shop/pim`. PHP/API, .htaccess и посторонние файлы сохраняются.

Проверено на опубликованных URL: 8 проверок скачивания, установки и отката. Дополнительно: 13 локальных проверок, включая автоматический откат при искусственном сбое. Фактический хостинг этими тестами не менялся.

После установки: Ctrl+F5 и проверка версии 10.8.0. Сохраните полный JSON export. Категории при необходимости мигрируются отдельно. Новая модель включается в «Якість і дані» через PREVIEW → APPLY.

**До APPLY проверьте последствия:** строгая публикация исключает неподтверждённые размеры, нарушенную маржу и недоступные варианты. Старая копия наличия требует свежего прайса. Для отправки новых полей сервер магазина должен поддерживать product_model_version>=1; без этого PIM остановит POST с объяснением. Backend магазина в этом релизе не изменён.
