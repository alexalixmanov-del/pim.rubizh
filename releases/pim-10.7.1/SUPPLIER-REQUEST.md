# Запрос поставщику

Добрий день! Ми автоматизуємо оновлення товарів у магазині «Рубіж». Підкажіть, будь ласка, чи можете надати постійне посилання на актуальний прайс у XLSX, CSV або XML, щоб наша система могла регулярно його завантажувати без ручного входу на сайт?

Потрібні такі дані:

- стабільний ID товару та унікальний ID/артикул кожного варіанта, назва, розмір і колір окремими полями;
- вихідна категорія, повний шлях категорій і підкатегорія окремими полями, якщо є вкладеність;
- закупівельна ціна, валюта та РРЦ, якщо вона обов’язкова;
- актуальний залишок або точний статус наявності;
- можливість виготовлення під замовлення та підтверджений строк у робочих/календарних днях для відповідних позицій;
- повний опис, характеристики, комплектація й посилання на фото;
- позначення знятих із продажу товарів.

Також уточніть, як часто оновлюється файл, чи змінюється посилання і чи можна завантажувати його з браузера з домену https://pim.rubizh.shop (CORS). Якщо доступ лише через API або сервер, надішліть опис способу підключення та обмеження частоти запитів. Потрібен також порядок трактування товарів, які зникли з файлу: тимчасово відсутні чи зняті з продажу?

Якщо один артикул має спільний залишок для кількох розмірів, просимо зазначити це окремо, щоб не дублювати кількість. Дякуємо!
