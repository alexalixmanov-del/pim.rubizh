# Установка 10.7.1 через adm.tools

В терминале хостинга выполните:

```bash
curl -fL --connect-timeout 20 --max-time 60 'https://raw.githubusercontent.com/alexalixmanov-del/pim.rubizh/f45430d507ccfafcad758a6d520607f51be0168f/releases/pim-10.7.1/install-from-github.sh' -o /tmp/rubizh-pim-install-10.7.1.sh && bash /tmp/rubizh-pim-install-10.7.1.sh
```

Проверено скачивание опубликованного установщика и архива, SHA-256, установка в изолированный каталог и откат (8 проверок). Целевая папка по умолчанию: /home/xk589064/rubizh.shop/pim. Предыдущие файлы сохраняются вне webroot; установщик выведет точную команду отката. Фактический хостинг этими проверками не изменялся.

Далее: Ctrl+F5 → Категоризація → Перевірити всі товари повторно (до первой миграции — Dry run міграції) → Застосувати перевірені категорії. Файлы обновляются отдельно от данных каталога; перед применением категорий PIM создаёт резервные копии.
