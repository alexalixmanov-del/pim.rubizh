# PIM 10.5.3 — одинаковые размеры и цвета разрешены

Совпадение размера и цвета само по себе не является ошибкой. Диагностика сравнивает варианты внутри одной карточки; разные карточки между собой не сравниваются. Однако даже внутри одной карточки варианты могут различаться другими характеристиками или артикулами.

## Исправления

- Совпадения внутри карточки показываются в свёрнутом справочном разделе с явным описанием области проверки. Они исключены из счётчика ошибок и не отмечаются красным.
- Импорт больше не выставляет блокирующий `source_review_reason=duplicate_source` только на основании одинакового размера и цвета. Другие причины проверки сохраняются.
- Исторический флаг `duplicate_source` самостоятельно не препятствует выгрузке товаров, рекламных фидов и формированию каталога для комплектов. Флаги независимых проверок продолжают действовать.
- Разделение карточки остаётся ручным действием после проверки данных поставщика. Размер и цвет не являются основанием для автоматического удаления, объединения или разделения вариантов.

Каталог пользователя не редактировался, размеры, цвета, артикулы и SKU не изменялись. В исходной резервной копии обнаружены те же 59 групп совпадений; это результат группировки, а не количество доказанных ошибок.

## Проверки

128/128 автоматических проверок, в том числе семь новых сценариев: одинаковые размеры/цвета в разных карточках; справочное совпадение внутри одной карточки; выгрузка обоих SKU с историческим флагом; сохранение независимой блокировки; оформление подсказки; поведение импорта и защита независимой причины проверки.

В Chromium проверены свёрнутая подсказка, отсутствие красной метки и ошибочного счётчика, выгрузка обоих SKU, сохранение поведения после перезагрузки, ширины 1440/390. Внешние запросы при проверке интерфейса блокировались. Результаты: `check-matching-options-tests.txt` и `check-matching-options-browser.json`.

Публикация артефакта на GitHub не устанавливает обновление на хостинге. Для установки используется терминал adm.tools с проверкой SHA-256 и резервированием прежних файлов.
